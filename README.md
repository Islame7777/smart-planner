# 🎯 Smart Planner

Smart Planner is a personalized activity recommendation platform built with Streamlit and Neo4j, designed to generate customized activity plans based on user profiles and preferences.

## 🚀 Features

- Personalized Activity Recommendations
- Graph-Based Recommendation Engine
- User Profile Management
- Administrator Dashboard
- Interactive Web Interface
- Data Visualization

## 🛠 Technologies Used

### Backend
- Python
- Streamlit

### Database
- Neo4j

### Data Processing
- Pandas
- NumPy

### Recommendation Engine
- Graph Analytics
- Personalized Recommendations

## 📊 Objectives

- Analyze user preferences
- Generate tailored activity plans
- Improve recommendation quality
- Explore graph database technologies
